      How VeriCell works

      A fixed pipeline does the heavy work, Muse Spark makes decisions only where judgement is needed, and plain code computes every number, so the AI can't invent one.

      1 · Find

      • Muse Spark reads the image and plans the question
      • Cellpose-SAM and SAM 3.1 find every object, zoomed in
      • A verifier scores each object: how likely is it real?

      2 · Check (the agent)

      • Muse Spark chooses one action at a time: judge a crop, re-ask SAM, or ask you
      • A safety gate blocks invalid actions and enforces budgets
      • After each action the answer is re-measured; it stops when sure

      3 · Answer

      • Exact geometry, no AI arithmetic
      • A 90% range, calibrated on held-out images
      • Your checks narrow the range live
