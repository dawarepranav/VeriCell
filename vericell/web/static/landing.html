01 · The problem

The best cell segmenter quietly gets about 1 in 5 cells wrong.

Almost every measurement in cell biology starts with AI outlining each cell or organoid. Drug screens, cancer research and neuroscience imaging all measure from those outlines. The errors are silent, an image can hold hundreds of objects, and nobody re-checks them all by hand.

1 in 5

cells missed or mis-drawn by Cellpose-SAM on our LIVECell test (recall 0.81), with no warning. In one dense image SAM 3.1 alone found 24 of 691 cells. Answers like “the largest organoid is 31,000 px²” come with no error bar, so a reader can’t tell a solid number from a lucky guess.

02 · How it works

A fixed pipeline does the work. Muse Spark decides only where judgement is needed.

Plain code computes every number, so the model can’t invent one. You see each step as it happens.

01

Look & plan

Muse Spark reads the image, names the objects in words SAM understands, and turns your question into a strict plan.

02

Find every object

Cellpose-SAM at three scales plus SAM 3.1 on zoomed tiles. Two independent opinions on every object.

03

Check each one

A verifier turns 22 signals into an honest probability that each object is real. An agent decides what to double-check.

04

Answer with a range

Exact geometry gives the answer; a 90% range calibrated on held-out images says how sure it is. Your checks narrow it live.

05 · The agent

It notices its own mistakes and decides what to check.

A harness keeps it honest: one tool at a time, a safety gate, budgets, and a stop rule.

Evaluator

07 · What didn’t work

Reported on purpose, because honesty about uncertainty is the point.

  • On LIVECell cells, fusion doesn’t beat Cellpose-SAM’s F1 (0.851 vs 0.857); the gain there is knowing which cells are wrong.
  • The Muse Spark crop judge is right 70–72% of the time on “one organoid or several?”; a fine-tuned Muse Glimmer reached 61%.
  • Showing the judge labelled example crops didn’t help.
  • 90% ranges are wide on hard images: most answers are within a few percent, about 1 image in 10 fails badly.
  • The benchmark was rebuilt as 68 images (the paper used 69 and doesn’t list them).
FAQ

Questions

Is this for diagnosis?

No. VeriCell is for research images only.

Does the AI calculate the numbers?

No. Muse Spark plans and judges; areas, counts and ranges are computed by plain code that matches the benchmark’s formulas exactly.

What does the 90% range mean?

On images it never trained on, the true answer fell inside the range 89–92% of the time. A wide range is the system honestly saying “check this”.

Can I run it on my own images?

Yes, locally: clone the repo, add your Meta API key, run make serve. The public demo uses four example images.
